# Code of Conduct

This project welcomes technical disagreement and careful security review. Participate with accuracy, respect, and enough evidence for another person to reproduce a claim.

Harassment, threats, personal attacks, doxxing, spam, and deliberate disclosure of another person’s credentials or private data are not acceptable. Do not publish exploit-ready details before maintainers have had a reasonable opportunity to respond privately.

Report conduct concerns through the repository owner’s private GitHub contact or a private security advisory when the concern includes a vulnerability. Maintainers may edit, hide, or remove contributions that violate these expectations and may restrict participation when necessary.
